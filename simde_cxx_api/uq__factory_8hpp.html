Parses a "UQ Type" module-input string into a UQKind.

This is the single place the accepted "UQ Type" string literals are spelled out; UQInitializer and UQAtomSymmBlockedDriver's tests both rely on this mapping staying in sync with UQFactory's construction logic.

decltype(auto) simde::visit_uq_kind ( UQKind  kind,
VisitorType &&  visitor 
)

Calls visitor with the floating-point type kind names.

UQFactory builds type-erased values. Modules which fill a buffer of a compile-time type use this function to turn the run-time kind of a factory into that type, e.g.,

auto t = visit_uq_kind(factory.kind(), [&](auto type) {
using float_type = typename decltype(type)::type;
return fill_tensor<float_type>(...);
});
Template Parameters
FloatTypeThe floating-point type the uncertain types are built on, and the type used for UQKind::none. Defaults to double.
VisitorTypeThe type of the visitor. Must be callable with std::type_identity<T> for each type T, and return the same type for each.
Parameters
[in]kindThe UQ kind to dispatch on.
[in]visitorThe callable to call.
Returns
Whatever visitor returns.
Exceptions
std::runtime_errorif kind is not a known UQKind. Strong throw guarantee.
???if visitor throws. Same throw guarantee.
