Detailed Description

Polymorphic base class for constructing a UQ scalar from a center and a radius.

The UQFactorBase class is used as a PIMPL for UQFactory (below) so that

Each UQ representation (sigma::Uncertain, sigma::Interval, sigma::Affine, sigma::ThresholdedAffine) is an independent template class with no shared base in sigma/tensorwrapper (they're unified only by compile-time traits). This class supplies the runtime-polymorphic base UQInitializer needs so it can hand back "a factory for whichever UQ kind the caller asked for" as a single result type, and so downstream code (UQAtomSymmBlockedDriver's Kernel) can construct UQ values without a compile-time dependence on which kind was selected.

N.b., only double centers/radii are supported at present. If/when needed the API could be extended to other types.
